# 部署、安全与故障边界

状态：部署建议，未上线、未配置凭据、未量测目标机器资源。本公开文档不记录现有基础设施地址、网络拓扑、连接配置或运维故障详情。

## 推荐职责分离

- 云端 VPS：轻量 Decision Service、HTTP/MCP 入口、认证、限流、审计与有界缓存；模型计算由 OpenAI 承担，不需要 GPU。
- 既有协调与执行端：保留任务派发、原检查点接续和业务执行职责，作为服务调用者。
- 既有 Hindsight：复用已有记忆服务，不复制第二套记忆库。
- 具体部署实例、域名、私网路由和密钥在私有运维配置中管理，不写入公开仓库。

“公共服务”指多个授权项目共享，并非匿名开放。公开源代码不意味着公开运行中的服务或业务数据。

## 上线前核验

- 目标 VPS 当前资源、峰值负载与新服务预算；
- 到 OpenAI 的服务可用性、区域支持、账户额度和出站连接；
- 每个调用方到服务的身份认证与网络连通；
- 到 Hindsight 的链路、时延和故障影响；
- 真实运行状态、备份与恢复能力。

小规模 MVP 可考虑轻量单实例与持久审计；是否用 SQLite、并发规模、备份策略和高可用要求待评审。不要预先承诺高并发、HA、端到端毫秒延迟或固定加速倍数。无需为初始化仓库购买新服务器。

## 隔离与权限

- 独立服务账户、运行目录、资源配额及存储，可复用基础入口设施，但不共用其他服务的业务数据库。
- API key 保存在服务端安全配置中，不进仓库、Skill、项目上下文或日志。
- 按调用者及项目限定 decision_kind、bank、预算和数据范围；不接受 payload 中自报身份作为授权。
- 使用最小模型与接口权限；账户/key 权限仍需实施时实际验证。
- 新增凭据、持久授权、认证配置或网络路由，在实施阶段按具体变更取得所需批准。
- 不提供任意命令执行、shell、业务派发或用户审批写入口。

## 故障处理

| 故障 | 预期行为 |
| --- | --- |
| Decisions 超时/拒绝/返回异常 | unavailable 或 review，回退原负责人路径 |
| Hindsight 不可用 | 按场景显式降级或 abstain，不凭空补历史 |
| 决策服务故障 | 回到原流程，不让建议服务成为全系统唯一可用路径 |
| 业务执行端离线 | 不声称已派发、执行或接续，沿原执行者恢复 |
| 反馈写回失败 | 原 ID 有界补写，业务结果和记忆写回状态分离 |
| 输入版本过期 | 拒绝应用旧建议，重新取当前状态 |
| 业务执行结果未知 | 原 ID 对账，不因模型建议重试而重新执行 |

本项目不承担既有执行器、消息收集器或审批通知系统的修复；这些是独立依赖，不得隐藏在决策服务上线声明中。
